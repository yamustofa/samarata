# Product Requirements Document (PRD)

# FOODISC

**Split Food Delivery Discounts Fairly**

Version: 1.0

---

# 1. Overview

## Vision

FOODISC is a simple web application that helps groups fairly split food delivery payments after applying platform discounts and service fees.

Instead of manually calculating everyone's payment using spreadsheets or calculators, users only need to enter:

* total discount
* service fee
* participant bills

FOODISC automatically distributes the discount proportionally based on each person's original bill and generates a shareable receipt.

---

# 2. Problem Statement

When ordering food together, people often ask:

> "How much do I need to pay after the discount?"

Most groups calculate this manually.

Common problems:

* incorrect calculations
* unfair discount distribution
* confusing spreadsheets
* difficult to share results
* takes several minutes

FOODISC solves this in less than one minute.

# 14. MVP Scope

The first release should focus on one polished workflow:

1. **Landing page** with a clear value proposition and a single "Calculate Now" CTA.
2. **Order setup** to enter the discount, service fee, and an optional order name.
3. **Participants** page to add names and original bill amounts with inline validation.
4. **Results** page showing total savings, each participant's original amount, final payment, and savings.
5. **Share** options to export a receipt as an image, copy it as text, or use the native share dialog.

By keeping the MVP focused on this end-to-end journey, FOODISC delivers immediate value while leaving room for enhancements like saved groups, reusable orders, multiple themes, and cloud synchronization in later releases.
